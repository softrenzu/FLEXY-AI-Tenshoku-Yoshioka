# 逆面接AI — FLEXY AI Tenshoku Yoshioka

「面接されるのは、会社のほうだ。」

FLEXY AIハッカソン 2026 用のプロトタイプ。求職者の希望を入力すると、企業AIとの模擬逆面接と企業比較を体験できます。

## 使い方
`index.html` をブラウザで開くか、GitHub Pagesで公開してください。ビルド不要です。

1. 希望職種、年収、働き方を入力
2. 「AIに企業を逆面接させる」をクリック
3. 模擬対話と企業比較を確認

## GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
反映後、`https://softrenzu.github.io/FLEXY-AI-Tenshoku-Yoshioka/` で利用できます。

## 重要な注意
- 企業名・企業回答・給与などはすべて架空のデモデータです。
- 現時点で実際のAI API通信、企業への問い合わせ、採用適性の実測評価は実装していません。
- 配布された非公開データやAPIキーは含みません。
- イベント成果物の公開・権利条件については主催者に確認してください。
- サムネイル画像は別途制作・提出が必要です。
