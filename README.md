# 逆面接AI — FLEXY AI Tenshoku Yoshioka

「面接されるのは、会社のほうだ。」

FLEXY AIハッカソン（2026年10月17日）向け。候補者の希望条件を受け取り、企業への逆面接を疑似体験し、企業側の回答と比較結果を見られるWebアプリです。

## 現在実装されているもの

- 希望職種・希望年収・重視条件の入力
- 架空企業4社から、希望条件に基づく比較と上位3社の抽出
- 求職者AIと企業AIを模した逆面接会話の表示
- 年収・リモート勤務・残業・成長支援・評価透明性を用いた説明可能なスコア
- 各社の良い点と入社前に確認すべき点の提示
- 印刷・PDF保存、スマートフォン対応
- 広告用サムネイルのSVG原稿（thumbnail.svg）

**重要：** 現行版は実際のAI APIに接続していません。架空企業データと明示されたルールベースのデモであり、実在企業との通信、実在企業の評価、採用適性の実測は行いません。

## ファイル構成

- index.html：ページの構造
- styles.css：レイアウト・スマートフォン対応
- app.js：架空企業データ、逆面接の会話、重み付け比較ロジック
- thumbnail.svg：広告用1200×630サムネイル原稿

## ローカル起動

index.html をブラウザで開いてください。依存ライブラリはありません。インターネットなしで動作します。

リポジトリの Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save。

有効化され反映されると下記のURLでアクセスできるようになります。

https://softrenzu.github.io/FLEXY-AI-Tenshoku-Yoshioka/

GitHub Pagesの設定変更は自動実行されていません。公開URLが使えることは別途確認してください。

## 配布データの取り扱い

イベント主催者の共有Driveフォルダは、接続中アカウントから内容を取得できませんでした。そのため、**サンプルファイルはまだ本リポジトリに取り込んでいません**。

- 現在の企業データはすべて架空であり、配布データとは異なります。
- 主催者が配布データの利用を認めても、一般公開まで認めたとは限りません。
- このリポジトリはPublicなので、公開可能なデータだけをコミットしてください。

## 提出について

通常のハッカソン向け成果物はサムネイルと動くプロトタイプです。thumbnail.svg はサムネイルの原稿であり、運営指定の画像形式に変換して提出してください。提出方法や特例は受付に最終確認してください。

## AI機能を追加する場合

実際のLLM接続にはサーバー側のAPIエンドポイントが必要です。GitHub PagesだけではAPIキーを安全に保管できません。Vercel・さくらのNode.js対応環境などを使い、APIキーをサーバー環境変数で管理してください。ブラウザ側のJavaScriptやPublicリポジトリにAPIキーを直接書かないでください。
